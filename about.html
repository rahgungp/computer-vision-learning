Tentang

COM Computer Vision Learning

Digital codelab untuk mata kuliah Computer Vision di Program Studi Teknik Komputer, Universitas Warmadewa. Menggabungkan teori, penjelasan visual, ilustrasi, contoh, praktik, dan refleksi dalam satu alur belajar.

Filosofi: konsep dulu, kode kemudian

Modul ini sengaja menahan diri untuk tidak langsung membawa mahasiswa ke deep learning atau pemrograman. Setiap materi membangun pemahaman dengan urutan WHAT → WHY → HOW → WHEN sebelum masuk ke CODE. Konvolusi, misalnya, dihitung manual dengan matriks kecil terlebih dahulu; fungsi Conv2D() baru muncul setelah mahasiswa memahami apa yang terjadi di baliknya.

Presentation Mode untuk dosen

Setiap halaman materi memiliki tombol ⛶ Fullscreen pada content toolbar. Ketika diaktifkan, sidebar dan header disembunyikan, tipografi serta ilustrasi diperbesar, dan halaman dapat digunakan langsung sebagai media mengajar. Tekan F atau Ctrl+Shift+F untuk mengaktifkan, panah ← → untuk berpindah bagian, dan Esc untuk keluar.

Penjadwalan materi

Materi yang belum dijadwalkan ditampilkan sebagai Coming Soon. Judul, deskripsi, dan capaian pembelajaran tetap terlihat, tetapi isi materinya belum ada. Pengaturannya dilakukan melalui satu berkas konfigurasi, assets/js/course-config.js, dan dijelaskan lengkap di README repositori.

⚠ Catatan penting

GitHub Pages adalah static hosting. Menyembunyikan materi di sisi klien bukan mekanisme keamanan, melainkan penjadwalan konten. Isi materi yang terkunci memang belum ditulis di dalam berkasnya, sehingga tidak ada yang dapat diakses lebih awal melalui view-source.

Sumber akademik

Struktur dan terminologi modul ini bersumber pada Hugging Face Community Computer Vision Course, sebuah kurikulum komunitas terbuka. Format penyajian codelab terinspirasi oleh JTI Polinema Flutter Codelab. Seluruh identitas visual, tata letak, kode, dan ilustrasi pada situs ini dibuat sendiri untuk COM Computer Vision.

Teknologi

HTML5, CSS3, dan JavaScript vanilla tanpa framework maupun proses build. Seluruh tautan aset memakai path relatif sehingga situs berjalan baik ketika dibuka langsung dari index.html maupun ketika di-deploy ke GitHub Pages.
