🧪 Praktikum 12

Optical Flow & Action Recognition

Menghitung gerakan antar frame dan mengklasifikasikan aksi pada klip nyata

⏱ 110 menit 🧰 Google Colab · OpenCV · Hugging Face Transformers 📖 Materi 12
▶ Buka Google Colab Baru 📖 Kembali ke Materi 12

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • menghitung optical flow dengan OpenCV dan memverifikasinya terhadap hitungan manual Materi 12;
  • memvisualisasikan medan vektor gerakan pada video nyata;
  • mengekstrak dan menyusun frame video menjadi tensor yang siap dipakai model;
  • menjalankan model action recognition pretrained dan menafsirkan hasilnya.

02Langkah 1 — Optical flow dengan OpenCV

import cv2
import numpy as np

cap = cv2.VideoCapture("video_sendiri.mp4")
ret, frame1 = cap.read()
prev_gray = cv2.cvtColor(frame1, cv2.COLOR_BGR2GRAY)

ret, frame2 = cap.read()
gray = cv2.cvtColor(frame2, cv2.COLOR_BGR2GRAY)

flow = cv2.calcOpticalFlowFarneback(
    prev_gray, gray, None,
    pyr_scale=0.5, levels=3, winsize=15,
    iterations=3, poly_n=5, poly_sigma=1.2, flags=0
)
# flow[y, x] = [u, v] -- komponen pergeseran pada titik (x, y)
print("Flow rata-rata (u, v):", flow.reshape(-1, 2).mean(axis=0))

03Langkah 2 — Verifikasi arah gerakan horizontal

Ix = cv2.Sobel(prev_gray, cv2.CV_64F, 1, 0, ksize=3)  # sama seperti Materi 03
It = gray.astype(float) - prev_gray.astype(float)

# Pilih satu titik dengan gradient horizontal kuat dan bandingkan u manual vs OpenCV
y, x = 200, 150
u_manual = -It[y, x] / (Ix[y, x] + 1e-6)
u_opencv = flow[y, x, 0]
print(f"u manual = {u_manual:.2f}   u OpenCV = {u_opencv:.2f}")

Selisih keduanya wajar ada (OpenCV memakai metode Farneback yang lebih canggih daripada constraint equation satu titik), tetapi arah dan skalanya harus sama-sama masuk akal.

04Langkah 3 — Visualisasikan medan vektor

import matplotlib.pyplot as plt

step = 16
h, w = gray.shape
Y, X = np.mgrid[0:h:step, 0:w:step]
U = flow[::step, ::step, 0]
V = flow[::step, ::step, 1]

plt.imshow(frame2[..., ::-1])
plt.quiver(X, Y, U, V, color="yellow", angles="xy", scale_units="xy", scale=0.5)
plt.title("Medan vektor optical flow")
plt.axis("off"); plt.show()

05Langkah 4 — Action recognition pada klip

from transformers import VideoMAEImageProcessor, VideoMAEForVideoClassification
import av

def baca_frame(path_video, n_frame=16):
    container = av.open(path_video)
    frames = [f.to_ndarray(format="rgb24") for f in container.decode(video=0)]
    idx = np.linspace(0, len(frames) - 1, n_frame).astype(int)
    return [frames[i] for i in idx]

processor = VideoMAEImageProcessor.from_pretrained("MCG-NJU/videomae-base-finetuned-kinetics")
model = VideoMAEForVideoClassification.from_pretrained("MCG-NJU/videomae-base-finetuned-kinetics")

klip = baca_frame("video_sendiri.mp4")
print("Ukuran tensor klip:", len(klip), "frame x", klip[0].shape)

inputs = processor(klip, return_tensors="pt")
outputs = model(**inputs)
probs = outputs.logits.softmax(-1)[0]
top5 = probs.topk(5)
for skor, idx in zip(top5.values, top5.indices):
    print(f"{model.config.id2label[idx.item()]:<30} {skor.item():.3f}")

06Checklist Verifikasi

  • Optical flow berhasil dihitung pada minimal satu pasang frame dari video sendiri.
  • Perbandingan u manual vs OpenCV sudah dilakukan dan masuk akal arah/skalanya.
  • Medan vektor optical flow tervisualisasikan di atas frame video.
  • Model action recognition berhasil dijalankan dan top-5 prediksi dicatat.
