🧪 Praktikum 14

Quantization, Pruning & ONNX

Mengukur ukuran dan latensi model sebelum dan sesudah setiap teknik optimasi

⏱ 120 menit 🧰 Google Colab · PyTorch · ONNX Runtime 📖 Materi 14
▶ Buka Google Colab Baru 📖 Kembali ke Materi 14

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • mengukur ukuran dan latensi model baseline secara sistematis;
  • menerapkan post-training quantization dan mengukur dampaknya secara kuantitatif;
  • mengekspor model ke ONNX dan membandingkan latensinya dengan PyTorch asli;
  • menerapkan structured pruning sederhana dan memverifikasi penghematan parameter.

02Langkah 1 — Ukur baseline

import torch, time, os
from torchvision.models import resnet50

model = resnet50(weights="IMAGENET1K_V2").eval()
torch.save(model.state_dict(), "baseline.pt")
ukuran_baseline = os.path.getsize("baseline.pt") / 1e6

dummy = torch.randn(1, 3, 224, 224)
with torch.no_grad():
    for _ in range(10): model(dummy)          # warm-up
    mulai = time.perf_counter()
    for _ in range(100): model(dummy)
    latensi_baseline = (time.perf_counter() - mulai) / 100 * 1000  # ms

print(f"Baseline  : {ukuran_baseline:.1f} MB, {latensi_baseline:.2f} ms/inferensi")

03Langkah 2 — Quantization dan pengukuran ulang

model_int8 = torch.quantization.quantize_dynamic(
    model, {torch.nn.Linear}, dtype=torch.qint8
)
torch.save(model_int8.state_dict(), "int8.pt")
ukuran_int8 = os.path.getsize("int8.pt") / 1e6

with torch.no_grad():
    for _ in range(10): model_int8(dummy)
    mulai = time.perf_counter()
    for _ in range(100): model_int8(dummy)
    latensi_int8 = (time.perf_counter() - mulai) / 100 * 1000

print(f"INT8      : {ukuran_int8:.1f} MB, {latensi_int8:.2f} ms/inferensi")
print(f"Rasio ukuran: {ukuran_baseline/ukuran_int8:.2f}×")
print(f"Rasio latensi: {latensi_baseline/latensi_int8:.2f}×")

04Langkah 3 — Ekspor ke ONNX

torch.onnx.export(model, dummy, "model.onnx", opset_version=13)

import onnxruntime as ort
sesi = ort.InferenceSession("model.onnx")
nama_input = sesi.get_inputs()[0].name

dummy_np = dummy.numpy()
for _ in range(10): sesi.run(None, {nama_input: dummy_np})
mulai = time.perf_counter()
for _ in range(100): sesi.run(None, {nama_input: dummy_np})
latensi_onnx = (time.perf_counter() - mulai) / 100 * 1000

print(f"ONNX Runtime: {latensi_onnx:.2f} ms/inferensi")

05Langkah 4 — Structured pruning sederhana

import torch.nn.utils.prune as prune

conv = model.layer1[0].conv1       # contoh satu lapisan konvolusi ResNet50
param_sebelum = sum(p.numel() for p in conv.parameters())

prune.ln_structured(conv, name="weight", amount=0.3, n=2, dim=0)  # pangkas 30% output channel
prune.remove(conv, "weight")       # jadikan permanen (bukan sekadar mask)

param_sesudah = (conv.weight != 0).sum().item()
print(f"Parameter sebelum : {param_sebelum}")
print(f"Parameter tersisa (bukan nol) : {param_sesudah}")
print(f"Penghematan: {(1 - param_sesudah/param_sebelum)*100:.1f}%")   # harus mendekati 29.7%

06Checklist Verifikasi

  • Ukuran dan latensi baseline (FP32) sudah dicatat.
  • Ukuran dan latensi INT8 sudah dicatat, rasio penghematan dibandingkan dengan hitungan manual Materi 14.
  • Model berhasil diekspor ke ONNX dan latensinya diukur lewat ONNX Runtime.
  • Structured pruning diterapkan pada minimal satu lapisan, penghematan parameter mendekati target 30%.
