Zero-Shot dengan CLIP & OWL-ViT

Contrastive loss manual, klasifikasi zero-shot, dan deteksi open-vocabulary

⏱ 120 menit 🧰 Google Colab · Hugging Face Transformers 📖 Materi 09
▶ Buka Google Colab Baru 📖 Kembali ke Materi 09

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • mengimplementasikan contrastive loss (InfoNCE) dari nol memakai NumPy dan memverifikasinya terhadap hitungan manual Materi 09;
  • menjalankan CLIP zero-shot classification pada foto sendiri dengan berbagai kandidat kelas;
  • menguji sensitivitas template kalimat terhadap skor kemiripan;
  • menjalankan OWL-ViT untuk deteksi objek dengan query teks bebas;
  • menganalisis kasus kegagalan zero-shot dan mengaitkannya dengan cara model dilatih.

02Langkah 1 — Contrastive loss dari nol

import numpy as np

def softmax(x):
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

I = np.array([[1, 0], [0, 1]], dtype=float)          # embedding citra (sudah satuan)
T = np.array([[0.9, 0.436], [0.436, 0.9]], dtype=float)  # embedding teks (sudah satuan)

sim = I @ T.T                 # matriks kemiripan N x N
p_i2t = softmax(sim)          # arah citra -> teks
p_t2i = softmax(sim.T)        # arah teks -> citra

label = np.arange(len(I))     # pasangan benar ada di diagonal
loss_i2t = -np.log(p_i2t[label, label]).mean()
loss_t2i = -np.log(p_t2i[label, label]).mean()
loss = (loss_i2t + loss_t2i) / 2

print("Matriks kemiripan:\n", sim)
print("Loss citra->teks :", round(loss_i2t, 3))
print("Loss total (symmetric):", round(loss, 3))

assert abs(loss_i2t - 0.488) < 1e-2, "belum cocok - periksa kembali implementasi Anda"
print("Cocok dengan hitungan manual Materi 09.")

03Langkah 2 — CLIP zero-shot classification

from transformers import CLIPProcessor, CLIPModel
from PIL import Image

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

img = Image.open("foto_sendiri.jpg")
kandidat = ["a photo of a cat", "a photo of a dog", "a photo of a car",
            "a photo of a building", "a photo of food"]   # tambahkan kandidat Anda sendiri

inputs = processor(text=kandidat, images=img, return_tensors="pt", padding=True)
outputs = model(**inputs)
probs = outputs.logits_per_image.softmax(dim=1)[0]

for teks, p in sorted(zip(kandidat, probs.tolist()), key=lambda x: -x[1]):
    print(f"{teks:<28} {p:.3f}")

Ulangi pada lima foto berbeda, lalu catat foto mana yang diklasifikasikan paling percaya diri (probabilitas tertinggi) dan mana yang paling ambigu.

04Langkah 3 — Uji sensitivitas template kalimat

kelas = "cat"
template = [
    kelas,
    f"a photo of a {kelas}",
    f"a close-up photo of a {kelas}",
    f"a blurry photo of a {kelas}",
]
inputs = processor(text=template, images=img, return_tensors="pt", padding=True)
probs = model(**inputs).logits_per_image.softmax(dim=1)[0]
for t, p in zip(template, probs.tolist()):
    print(f"{t:<35} {p:.3f}")

Bandingkan skor kata tunggal "cat" dengan kalimat lengkap. Template mana yang menghasilkan skor paling tinggi untuk citra Anda?

05Langkah 4 — OWL-ViT: deteksi open-vocabulary

from transformers import OwlViTProcessor, OwlViTForObjectDetection
import torch

processor = OwlViTProcessor.from_pretrained("google/owlvit-base-patch32")
model = OwlViTForObjectDetection.from_pretrained("google/owlvit-base-patch32")

img = Image.open("foto_ramai.jpg")
queries = ["an orange tuk-tuk", "a person riding a bicycle", "a white van"]  # bebas, bukan kelas COCO

inputs = processor(text=[queries], images=img, return_tensors="pt")
outputs = model(**inputs)

target_sizes = torch.tensor([img.size[::-1]])
hasil = processor.post_process_object_detection(
    outputs, threshold=0.1, target_sizes=target_sizes
)[0]

for box, score, label in zip(hasil["boxes"], hasil["scores"], hasil["labels"]):
    print(f"{queries[label]:<28} skor={score:.2f}  box={box.tolist()}")

06Checklist Verifikasi

  • Fungsi contrastive loss ditulis dari nol dan lolos assert terhadap hitungan Materi 09.
  • CLIP zero-shot dijalankan pada minimal lima foto dengan minimal lima kandidat kelas.
  • Eksperimen sensitivitas template kalimat sudah dijalankan dan dicatat hasilnya.
  • OWL-ViT berhasil mendeteksi minimal satu objek dari query teks yang bukan kelas COCO standar.
  • Minimal satu kasus kegagalan zero-shot (CLIP atau OWL-ViT) sudah didokumentasikan.
