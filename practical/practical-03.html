Preprocessing dengan Alasan

Histogram, interpolasi, filtering, kontras, thresholding, dan pipeline

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • membaca histogram dan menentukan operasi yang dibutuhkan sebelum mencoba-coba fungsi;
  • membandingkan efektivitas box, Gaussian, dan median filter pada jenis derau yang berbeda;
  • membandingkan threshold global, Otsu, dan adaptif pada pencahayaan tidak merata;
  • menyusun preprocessing pipeline yang setiap langkahnya beralasan.

02Persiapan

import cv2
import numpy as np
import matplotlib.pyplot as plt

gelap  = cv2.imread("gelap.jpg",  cv2.IMREAD_GRAYSCALE)
derau  = cv2.imread("derau.jpg",  cv2.IMREAD_GRAYSCALE)
timpang = cv2.imread("timpang.jpg", cv2.IMREAD_GRAYSCALE)   # pencahayaan tidak merata

⚠ Ingat urutan kanal OpenCV

cv2.imread() menghasilkan BGR, bukan RGB. Untuk menampilkan dengan Matplotlib, konversikan dulu: cv2.cvtColor(img, cv2.COLOR_BGR2RGB). Pada praktikum ini kita langsung membaca grayscale sehingga persoalan tersebut tidak muncul — tetapi kebiasaannya perlu dibangun sejak awal.

03Langkah 1 — Baca histogram lebih dulu

def tampil_histogram(citra, judul):
    fig, ax = plt.subplots(1, 2, figsize=(11, 3.5))
    ax[0].imshow(citra, cmap="gray", vmin=0, vmax=255)
    ax[0].set_title(judul); ax[0].axis("off")
    ax[1].hist(citra.ravel(), bins=256, range=(0, 256), color="#0d6b78")
    ax[1].set_title("Histogram"); ax[1].set_xlabel("intensitas")
    plt.tight_layout(); plt.show()

for c, j in [(gelap, "Gelap"), (derau, "Berderau"), (timpang, "Pencahayaan timpang")]:
    tampil_histogram(c, j)

Tuliskan kesimpulan Anda untuk setiap histogram sebelum menjalankan sel berikutnya. Langkah ini yang membedakan praktik beralasan dari coba-coba.

04Langkah 2 — Interpolasi pada resize

metode = {
    "NEAREST":  cv2.INTER_NEAREST,
    "BILINEAR": cv2.INTER_LINEAR,
    "BICUBIC":  cv2.INTER_CUBIC,
    "AREA":     cv2.INTER_AREA,
}

fig, ax = plt.subplots(1, 4, figsize=(16, 4))
for a, (nama, m) in zip(ax, metode.items()):
    kecil = cv2.resize(gelap, (64, 64), interpolation=m)
    a.imshow(cv2.resize(kecil, (256, 256), interpolation=cv2.INTER_NEAREST), cmap="gray")
    a.set_title(nama); a.axis("off")
plt.show()

05Langkah 3 — Tiga filter terhadap dua jenis derau

def tambah_salt_pepper(citra, rasio=0.05):
    keluar = citra.copy()
    n = int(rasio * citra.size / 2)
    ys, xs = np.random.randint(0, citra.shape[0], n), np.random.randint(0, citra.shape[1], n)
    keluar[ys, xs] = 255
    ys, xs = np.random.randint(0, citra.shape[0], n), np.random.randint(0, citra.shape[1], n)
    keluar[ys, xs] = 0
    return keluar

sp = tambah_salt_pepper(gelap)

hasil = {
    "Asli + salt&pepper": sp,
    "Box 3x3":    cv2.blur(sp, (3, 3)),
    "Gaussian":   cv2.GaussianBlur(sp, (3, 3), 0),
    "Median 3x3": cv2.medianBlur(sp, 3),
}
fig, ax = plt.subplots(1, 4, figsize=(16, 4))
for a, (nama, c) in zip(ax, hasil.items()):
    a.imshow(c, cmap="gray"); a.set_title(nama); a.axis("off")
plt.show()

Bandingkan ketiganya dengan cermat. Median filter seharusnya menang telak di sini — jelaskan mengapa pada laporan Anda, kaitkan dengan penjelasan di Materi 03.

06Langkah 4 — Kontras: equalization dan CLAHE

eq    = cv2.equalizeHist(gelap)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8)).apply(gelap)

for c, j in [(gelap, "Asli"), (eq, "Equalization"), (clahe, "CLAHE")]:
    tampil_histogram(c, j)

Perhatikan area yang semula datar: equalization sering ikut memperkuat derau di sana, CLAHE lebih terkendali.

07Langkah 5 — Tiga jenis thresholding

_, global_th = cv2.threshold(timpang, 127, 255, cv2.THRESH_BINARY)
_, otsu      = cv2.threshold(timpang, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
adaptif      = cv2.adaptiveThreshold(timpang, 255,
                                     cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                     cv2.THRESH_BINARY, 31, 10)

fig, ax = plt.subplots(1, 4, figsize=(16, 4))
for a, (nama, c) in zip(ax, {"Asli": timpang, "Global 127": global_th,
                             "Otsu": otsu, "Adaptif": adaptif}.items()):
    a.imshow(c, cmap="gray"); a.set_title(nama); a.axis("off")
plt.show()

Pada citra dengan pencahayaan tidak merata, threshold global dan Otsu akan gagal pada salah satu sisi citra. Tunjukkan bagian mana yang gagal dan kaitkan dengan bentuk histogramnya.

09Checklist Verifikasi
