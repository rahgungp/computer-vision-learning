🧪 Praktikum 06

Transfer Learning dari ResNet50

Feature extraction dan fine-tuning pada dataset kecil milik sendiri

⏱ 130 menit 🧰 Google Colab (GPU) · TensorFlow/Keras 📖 Materi 06
▶ Buka Google Colab Baru 📖 Kembali ke Materi 06

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • memuat model pretrained ImageNet (ResNet50) dan membekukannya sebagai feature extractor;
  • memasang dan melatih classifier head baru di atas base model yang beku;
  • melakukan fine-tuning dengan membuka sebagian lapisan teratas dan learning rate kecil;
  • menghitung jumlah parameter yang dibekukan vs dilatih pada setiap tahap;
  • membandingkan akurasi feature extraction murni dengan akurasi setelah fine-tuning.

⚠ Aktifkan GPU terlebih dahulu

Di Google Colab: Runtime → Change runtime type → T4 GPU. Tanpa GPU, pelatihan ResNet50 tetap bisa berjalan tetapi jauh lebih lambat.

02Langkah 0 — Siapkan dataset kecil

Kumpulkan atau unduh dataset dengan dua sampai lima kelas, minimal 50 citra per kelas, disusun dalam folder per kelas. Dataset publik kecil seperti cats_vs_dogs, tf_flowers, atau rock_paper_scissors dari TensorFlow Datasets juga bisa dipakai bila Anda belum punya dataset sendiri. 

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

train_ds = keras.utils.image_dataset_from_directory(
    "dataset/train", image_size=(224, 224), batch_size=32)
val_ds = keras.utils.image_dataset_from_directory(
    "dataset/val", image_size=(224, 224), batch_size=32)

n_kelas = len(train_ds.class_names)
print("Kelas:", train_ds.class_names)

03Langkah 1 — Feature extraction: bekukan base model

base_model = keras.applications.ResNet50(
    weights="imagenet", include_top=False, input_shape=(224, 224, 3)
)
base_model.trainable = False

preprocess = keras.applications.resnet50.preprocess_input

model = keras.Sequential([
    layers.Lambda(preprocess),
    base_model,
    layers.GlobalAveragePooling2D(),
    layers.Dropout(0.3),
    layers.Dense(n_kelas, activation="softmax"),
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
history_1 = model.fit(train_ds, validation_data=val_ds, epochs=10)

Catat akurasi validasi terbaik pada tahap ini — angka ini menjadi baseline pembanding untuk Langkah 2.

04Langkah 2 — Fine-tuning: buka lapisan teratas

base_model.trainable = True
for layer in base_model.layers[:-20]:      # bekukan semua KECUALI 20 lapisan teratas
    layer.trainable = False

model.compile(
    optimizer=keras.optimizers.Adam(1e-5),  # learning rate 100x lebih kecil dari tahap 1
    loss="sparse_categorical_crossentropy", metrics=["accuracy"]
)
history_2 = model.fit(train_ds, validation_data=val_ds, epochs=5)

✔ Bila akurasi validasi malah turun

Kemungkinan besar learning rate masih terlalu besar, atau jumlah lapisan yang dibuka terlalu banyak untuk ukuran dataset Anda — gejala catastrophic forgetting yang dibahas di Materi 06. Coba turunkan learning rate sekali lagi atau kurangi jumlah lapisan yang dibuka.

05Langkah 3 — Hitung parameter beku vs dilatih

def hitung_parameter(model):
    trainable = sum(tf.size(w).numpy() for w in model.trainable_weights)
    beku      = sum(tf.size(w).numpy() for w in model.non_trainable_weights)
    print(f"Trainable : {trainable:,}")
    print(f"Beku      : {beku:,}")
    print(f"Total     : {trainable + beku:,}")

hitung_parameter(model)

Bandingkan hasilnya dengan tabel pada bagian Example di Materi 06, lalu hitung berapa persen dari total 25,6 juta parameter ResNet50 yang benar-benar Anda latih pada tahap feature extraction dan pada tahap fine-tuning.

06Langkah 4 — Bandingkan dan visualisasikan

import matplotlib.pyplot as plt

acc_1 = history_1.history["val_accuracy"]
acc_2 = history_2.history["val_accuracy"]

plt.plot(range(1, len(acc_1) + 1), acc_1, label="Feature extraction")
plt.plot(range(len(acc_1) + 1, len(acc_1) + len(acc_2) + 1), acc_2, label="Fine-tuning")
plt.axvline(len(acc_1) + 0.5, color="gray", linestyle="--", label="mulai fine-tuning")
plt.xlabel("Epoch"); plt.ylabel("Validation accuracy"); plt.legend(); plt.show()

Satu grafik ini merangkum keseluruhan praktikum: di mana letak lompatan akurasi setelah fine-tuning dimulai, dan apakah lompatan itu bertahan atau justru menurun di epoch-epoch berikutnya?

07Checklist Verifikasi

  • Dataset tersusun rapi dalam folder per kelas, minimal 50 citra per kelas.
  • Model feature extraction (base beku) berhasil dilatih dan akurasi validasinya tercatat.
  • Model fine-tuning (20 lapisan teratas terbuka, learning rate 1e-5) berhasil dilatih.
  • Jumlah parameter trainable vs beku dihitung pada kedua tahap.
  • Grafik perbandingan akurasi feature extraction vs fine-tuning sudah dibuat.
