🧪 Praktikum 04

Deteksi, Deskripsi, dan Pencocokan Fitur

Harris, SIFT, ORB, brute-force, ratio test, FLANN, dan RANSAC

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • mendeteksi sudut dan menjelaskan mengapa sudut ditemukan di lokasi tertentu;
  • membandingkan SIFT dan ORB dari sisi jumlah keypoint, waktu, dan sebaran;
  • menerapkan brute-force matching, ratio test, dan FLANN;
  • menyaring outlier dengan RANSAC dan menunjukkan dampaknya.

02Persiapan

import cv2, time
import numpy as np
import matplotlib.pyplot as plt

img1 = cv2.imread("objek_a.jpg", cv2.IMREAD_GRAYSCALE)   # objek, sudut 1
img2 = cv2.imread("objek_b.jpg", cv2.IMREAD_GRAYSCALE)   # objek sama, sudut 2
polos = cv2.imread("polos.jpg",  cv2.IMREAD_GRAYSCALE)   # permukaan tanpa tekstur

print(img1.shape, img2.shape, polos.shape)

03Langkah 1 — Deteksi sudut Harris

def harris(citra, k=0.04, ambang=0.01):
    f = np.float32(citra)
    respons = cv2.cornerHarris(f, blockSize=2, ksize=3, k=k)
    warna = cv2.cvtColor(citra, cv2.COLOR_GRAY2BGR)
    warna[respons > ambang * respons.max()] = [255, 0, 0]
    return warna

plt.figure(figsize=(7, 5))
plt.imshow(harris(img1)); plt.axis("off"); plt.title("Sudut Harris")
plt.show()

Amati di mana sudut ditemukan dan di mana tidak. Cocokkan dengan penjelasan jendela pengamatan pada Materi 04: area datar tidak menghasilkan sudut, dan sepanjang tepi lurus pun jarang.

04Langkah 2 — SIFT vs ORB

sift = cv2.SIFT_create()
orb  = cv2.ORB_create(nfeatures=2000)

for nama, detektor in [("SIFT", sift), ("ORB", orb)]:
    t0 = time.time()
    kp, des = detektor.detectAndCompute(img1, None)
    dt = time.time() - t0
    print(f"{nama:5s}  keypoint={len(kp):5d}  "
          f"bentuk deskriptor={des.shape}  dtype={des.dtype}  waktu={dt:.3f}s")

Perhatikan dtype deskriptornya. SIFT menghasilkan bilangan riil, ORB menghasilkan bilangan bulat tak bertanda (deskriptor biner). Perbedaan inilah yang menentukan metrik jarak pada langkah berikutnya.

05Langkah 3 — Brute-force + ratio test

kp1, des1 = sift.detectAndCompute(img1, None)
kp2, des2 = sift.detectAndCompute(img2, None)

bf = cv2.BFMatcher()
kandidat = bf.knnMatch(des1, des2, k=2)

for ambang in [0.4, 0.75, 0.95]:
    lolos = [m for m, n in kandidat if m.distance < ambang * n.distance]
    print(f"ambang {ambang}: {len(lolos):4d} dari {len(kandidat)} kandidat")

baik = [m for m, n in kandidat if m.distance < 0.75 * n.distance]
vis = cv2.drawMatches(img1, kp1, img2, kp2, baik[:40], None,
                      flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS)
plt.figure(figsize=(14, 6)); plt.imshow(vis); plt.axis("off"); plt.show()

Catat ketiga angka tersebut — perubahannya menjelaskan peran ambang ratio test secara nyata.

06Langkah 4 — FLANN dan perbandingan waktu

index_params  = dict(algorithm=1, trees=5)      # KD-Tree untuk deskriptor riil
search_params = dict(checks=50)
flann = cv2.FlannBasedMatcher(index_params, search_params)

t0 = time.time(); bf.knnMatch(des1, des2, k=2);    t_bf    = time.time() - t0
t0 = time.time(); flann.knnMatch(des1, des2, k=2); t_flann = time.time() - t0
print(f"brute-force: {t_bf:.3f}s   FLANN: {t_flann:.3f}s")

📌 Untuk ORB

Deskriptor biner memerlukan konfigurasi berbeda: cv2.BFMatcher(cv2.NORM_HAMMING) untuk brute-force, atau indeks LSH (algorithm=6) untuk FLANN.

07Langkah 5 — RANSAC menyaring outlier

src = np.float32([kp1[m.queryIdx].pt for m in baik]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in baik]).reshape(-1, 1, 2)

H, mask = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
inlier = int(mask.sum())
print(f"{len(baik)} pasangan -> {inlier} inlier ({inlier/len(baik):.0%})")

vis = cv2.drawMatches(img1, kp1, img2, kp2, baik, None,
                      matchesMask=mask.ravel().tolist(),
                      flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS)
plt.figure(figsize=(14, 6)); plt.imshow(vis); plt.axis("off"); plt.show()

08Langkah 6 — Kasus gagal: permukaan polos

kp_polos, des_polos = sift.detectAndCompute(polos, None)
print("keypoint pada permukaan polos:", len(kp_polos))

Jumlahnya akan sangat sedikit, bahkan bisa nol. Ini bukan kesalahan kode Anda, melainkan batas pendekatan berbasis detektor. Di sinilah metode detector-free seperti LoFTR menjadi relevan.

09Checklist Verifikasi

  • Sudut Harris sudah divisualisasikan dan lokasinya dijelaskan.
  • Jumlah keypoint, bentuk deskriptor, dtype, dan waktu SIFT serta ORB sudah dicatat.
  • Ratio test sudah diuji pada tiga ambang berbeda dengan angka yang tercatat.
  • Waktu brute-force dan FLANN sudah dibandingkan.
  • Jumlah inlier setelah RANSAC sudah dicatat beserta persentasenya.
  • Kasus permukaan polos sudah diuji dan dijelaskan.
