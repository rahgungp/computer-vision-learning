Konvolusi dari Nol

Implementasi konvolusi dan pooling dengan NumPy murni, lalu CNN dengan framework

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • mengimplementasikan konvolusi 2D dari nol memakai NumPy murni;
  • memverifikasi implementasinya terhadap contoh hitungan manual;

03Langkah 1 — Tulis fungsi konvolusi sendiri

import numpy as np

def konvolusi_2d(citra, kernel, padding=0, stride=1):
    citra  = np.asarray(citra, dtype=float)
    kernel = np.asarray(kernel, dtype=float)
    kh, kw = kernel.shape

    if padding > 0:
        citra = np.pad(citra, padding, mode="constant", constant_values=0)

    h, w = citra.shape
    out_h = (h - kh) // stride + 1
    out_w = (w - kw) // stride + 1
    keluar = np.zeros((out_h, out_w))

    for i in range(out_h):
        for j in range(out_w):
            y, x = i * stride, j * stride
            area = citra[y:y + kh, x:x + kw]
            keluar[i, j] = np.sum(area * kernel)     # kalikan lalu jumlahkan
    return keluar

Perhatikan bahwa inti seluruh CNN ada pada satu baris: np.sum(area * kernel). Sisanya hanya urusan menggeser jendela.

import cv2, matplotlib.pyplot as plt

foto = cv2.imread("bangunan.jpg", cv2.IMREAD_GRAYSCALE).astype(float)

prewitt_h = np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]])   # perubahan horizontal
prewitt_v = np.array([[-1, -1, -1], [0, 0, 0], [1, 1, 1]])   # perubahan vertikal

fh = konvolusi_2d(foto, prewitt_h, padding=1)
fv = konvolusi_2d(foto, prewitt_v, padding=1)
magnitudo = np.sqrt(fh**2 + fv**2)

fig, ax = plt.subplots(1, 4, figsize=(18, 5))
for a, (j, c) in zip(ax, [("Asli", foto), ("Horizontal", np.abs(fh)),

    a.imshow(c, cmap="gray"); a.set_title(j); a.axis("off")

07Langkah 5 — Max pooling sendiri

def max_pooling(peta, ukuran=2, stride=2):
    h, w = peta.shape
    out_h = (h - ukuran) // stride + 1
    out_w = (w - ukuran) // stride + 1
    keluar = np.zeros((out_h, out_w))
    for i in range(out_h):
        for j in range(out_w):
            y, x = i * stride, j * stride
            keluar[i, j] = peta[y:y + ukuran, x:x + ukuran].max()
    return keluar

contoh = np.array([[ 12,  20,  30,  0],
                   [  8,  12,   2,  0],
                   [ 34,  70,  37,  4],
                   [112, 100,  25, 12]])
print(max_pooling(contoh))       # harus menghasilkan [[20, 30], [112, 37]]

08Langkah 6 — Barulah framework

Setelah seluruh mekanismenya Anda buktikan sendiri, bangun CNN kecil dan cocokkan jumlah parameternya dengan tabel pada bagian Example di Materi 05. 

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    keras.Input(shape=(28, 28, 1)),
    layers.Conv2D(32, (3, 3), activation="relu"),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation="relu"),
    layers.MaxPooling2D((2, 2)),
    layers.Flatten(),
    layers.Dropout(0.5),
    layers.Dense(10, activation="softmax"),
])
model.summary()      # cocokkan: total 34.826 parameter
