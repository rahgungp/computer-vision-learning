🧪 Praktikum 02

Membedah Citra sebagai Matriks

Pixel, kanal warna, grayscale manual, resolusi spasial dan intensitas

⏱ 100 menit 🧰 Google Colab · NumPy · Pillow 📖 Materi 02
▶ Buka Google Colab Baru 📖 Kembali ke Materi 02

01Tujuan Praktikum

Setelah praktikum ini, mahasiswa mampu:

  • membuktikan secara langsung bahwa citra adalah matriks angka;
  • membaca dan menafsirkan nilai pixel, bentuk array, dan tipe datanya;
  • memisahkan kanal warna dan membuat konversi grayscale secara manual;
  • mengamati dampak penurunan resolusi spasial dan resolusi intensitas.

02Persiapan

import numpy as np
import matplotlib.pyplot as plt
from PIL import Image

img = Image.open("foto.jpg").convert("RGB")
arr = np.array(img)

print("shape :", arr.shape)      # (tinggi, lebar, 3)
print("dtype :", arr.dtype)      # uint8
print("min   :", arr.min())
print("max   :", arr.max())

✔ Kebiasaan wajib

Empat baris print di atas dijalankan setiap kali Anda memuat citra, sepanjang semester. Sebagian besar kebingungan pada praktikum berikutnya bersumber dari tiga nilai ini.

03Langkah 1 — Membaca satu pixel

y, x = 100, 150
print("f(x=150, y=100) =", arr[y, x])     # ingat: [baris, kolom] = [y, x]

r, g, b = arr[y, x]
print(f"R={r}  G={g}  B={b}")

plt.imshow([[arr[y, x] / 255]])           # tampilkan warnanya
plt.axis("off"); plt.show()

Cocokkan warna yang muncul dengan nilai RGB-nya. Bila nilai R jauh lebih besar daripada G dan B, warnanya harus condong merah. Inilah verifikasi paling sederhana bahwa Anda membaca data dengan benar.

04Langkah 2 — Memisahkan kanal

R, G, B = arr[:, :, 0], arr[:, :, 1], arr[:, :, 2]

fig, ax = plt.subplots(1, 4, figsize=(16, 4))
ax[0].imshow(arr);            ax[0].set_title("RGB")
ax[1].imshow(R, cmap="gray"); ax[1].set_title("Kanal R")
ax[2].imshow(G, cmap="gray"); ax[2].set_title("Kanal G")
ax[3].imshow(B, cmap="gray"); ax[3].set_title("Kanal B")
for a in ax: a.axis("off")
plt.show()

print("bentuk satu kanal:", R.shape)   # (tinggi, lebar) - dua dimensi saja

Amati: area yang merah pada citra asli akan tampak terang pada kanal R dan gelap pada kanal B. Setiap kanal adalah citra grayscale tersendiri.

05Langkah 3 — Grayscale manual vs pustaka

# rata-rata sederhana - TIDAK sesuai persepsi mata
gray_rata = arr.mean(axis=2).astype(np.uint8)

# rata-rata berbobot - sesuai kepekaan mata manusia
gray_bobot = (0.299 * R + 0.587 * G + 0.114 * B).astype(np.uint8)

# hasil pustaka sebagai pembanding
gray_pil = np.array(Image.open("foto.jpg").convert("L"))

selisih = np.abs(gray_bobot.astype(int) - gray_pil.astype(int))
print("selisih rata-rata terhadap pustaka:", selisih.mean())

Selisih terhadap hasil pustaka seharusnya sangat kecil. Bandingkan pula gray_rata dan gray_bobot secara visual — perbedaannya paling terlihat pada area hijau dan biru.

06Langkah 4 — Menurunkan resolusi spasial

fig, ax = plt.subplots(1, 5, figsize=(18, 4))
for i, n in enumerate([256, 64, 32, 16, 8]):
    kecil = Image.fromarray(gray_bobot).resize((n, n))
    ax[i].imshow(np.array(kecil), cmap="gray")
    ax[i].set_title(f"{n} x {n}")
    ax[i].axis("off")
plt.show()

Catat pada ukuran berapa objek utama mulai tidak dikenali. Itulah batas resolusi untuk citra Anda.

07Langkah 5 — Menurunkan resolusi intensitas

def kuantisasi(citra, bit):
    tingkat = 2 ** bit
    langkah = 256 // tingkat
    return ((citra // langkah) * langkah).astype(np.uint8)

fig, ax = plt.subplots(1, 5, figsize=(18, 4))
for i, bit in enumerate([8, 4, 3, 2, 1]):
    ax[i].imshow(kuantisasi(gray_bobot, bit), cmap="gray", vmin=0, vmax=255)
    ax[i].set_title(f"{bit} bit = {2**bit} tingkat")
    ax[i].axis("off")
plt.show()

Amati munculnya pita-pita pada area bergradasi halus seperti langit atau dinding polos, sementara area berpola rapat tampak lebih tahan. Jelaskan mengapa demikian pada laporan Anda.

08Checklist Verifikasi

  • shape, dtype, minimum, dan maksimum sudah dicetak dan dipahami.
  • Nilai satu pixel sudah dicocokkan dengan warna yang ditampilkan.
  • Tiga kanal sudah dipisahkan dan ditampilkan sebagai grayscale.
  • Grayscale manual sudah dibandingkan dengan hasil pustaka disertai angka selisihnya.
  • Batas resolusi spasial dan resolusi intensitas sudah dicatat.

09Pengumpulan & Refleksi

  1. Mengapa rata-rata sederhana memberi hasil berbeda dari rata-rata berbobot? Kanal mana yang paling berpengaruh?
  2. Pada ukuran berapa objek utama Anda mulai tidak dikenali? Apa yang menentukan batas tersebut?
  3. Mengapa pita warna lebih terlihat pada area bergradasi halus daripada area bertekstur rapat?
  4. Berapa ukuran citra Anda tanpa kompresi? Bandingkan dengan ukuran berkas aslinya di disk.
